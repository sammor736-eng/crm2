# World Explorer Quiz

A mobile-friendly geography game for kids.

## Game flow
- Show a country flag with 3 country choices.
- After the answer, ask for that country's capital with 3 choices.
- Randomly insert U.S. state-capital questions.
- Track score and answer streaks.

## Deployment
This is a static site and can be imported directly into Vercel with no build command and no database.
